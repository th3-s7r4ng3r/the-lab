# Gracefully Stop K3s Cluster

In case for maintenance or any other reason, the cluster can be stopped gracefully and started again using the following commands.

## Stopping the Cluster

1. Cordon the nodes (all nodes):

   ```bash
   kubectl cordon <node-name>
   ```

2. Drain all pods from the nodes:

   ```bash
   kubectl drain <node-name> --ignore-daemonsets
   ```

3. SSH into the nodes and stop the k3s services:

   - In Worker Nodes:

     ```bash
     sudo systemctl stop k3s-agent
     ```

   - In Master Node:

     ```bash
     sudo systemctl stop k3s
     ```

4. Power Down the nodes:

    ```bash
    sudo shutdown -h now
    ```

## Starting the Cluster

1. Power on the Master node first and wait for k3s to be ready.

   ```bash
   kubectl get nodes
   ```

2. Power on the Worker nodes one by one and wait for k3s to be ready.

   ```bash
   kubectl get nodes
   ```

3. Uncordon the nodes and wait:

   ```bash
   kubectl uncordon <node-name>
   ```

4. Verify that all pods are running:

   ```bash
   kubectl get pods -A
   ```

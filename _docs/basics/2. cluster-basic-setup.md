# Environment Setup - Cluster Basic Setup

This document outlines the steps to set up basic components used by other worklods in the cluster. This includes cluster sotrage, monitoring, and security.

## Prerequisites

- A running Kubernetes cluster (version 1.20 or later recommended)
- `kubectl` configured to interact with the cluster

## Step 1: Taint Master Node (Optional)

Since this is a multi node cluster, the master node should not be used for running workloads (except selected workloads). To ensure this, taint the master node to prevent pods from being scheduled on it.

   ```bash
   kubectl taint nodes <master-node-name> node-role.kubernetes.io/control-plane:NoSchedule
   ```

## Step 2: Install Rancher (Optional)

1. Use the provided Terraform module to deploy Rancher in the `cattle-system` namespace.
2. Execute the following command to get the initial admin password:
   ```bash
   kubectl -n cattle-system get secret bootstrap-secret -o go-template='{{.data.bootstrapPassword | base64decode}}'
   ```
3. Access the Rancher UI at `https://<RANCHER_SERVER_IP>` and log in using the username `admin` and the password retrieved in the previous step.

## Step 3: Install Longhorn for Cluster Storage

1. Use the provided Terraform module to deploy Longhorn in the `management` namespace. These include multiple storage classes for different usecases.
2. Ensure the persistence volume size and storage classes can be seen in the Longhorn UI.
